Donny Beelo releases

Flatpak release repository. Add it once; everything below installs from it.

Add the repository

flatpak remote-add --if-not-exists donnybeelo https://releases.donnybeelo.net/donnybeelo.flatpakrepo

Applications

ApplicationIDInstall
Convey
Email client		 net.donnybeelo.Convey flatpak install donnybeelo net.donnybeelo.Convey

Updates

flatpak update

Signing

Releases are signed. The public key is embedded in donnybeelo.flatpakrepo, and available separately as donnybeelo-key.asc.

x86_64 only. Convey is a fork of Geary.
